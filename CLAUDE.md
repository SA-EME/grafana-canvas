## Project knowledge

This repository contains a **Grafana panel plugin** (`saeme-canvas-panel`) built by Saeme. You must Read @./.config/AGENTS/instructions.md before doing changes.

## What this plugin does

This plugin renders an interactive **SVG-based canvas** inside a Grafana panel, allowing users to build network/system topology maps: infrastructure diagrams, network maps, server rooms, etc.

Key capabilities:
- **Nodes** representing devices (switches, routers, generic equipment), draggable on the canvas
- **Links** (edges) between nodes drawn as SVG lines
- **Pan & zoom** viewport navigation on the canvas
- **Edit mode** for building/modifying the map interactively (add/delete nodes, draw links)
- **Data binding**: nodes can be linked to Grafana query results via a `dataId`, driving labels and colors
- **Color mapping** from Grafana field config thresholds/mappings applied to the bound data value
- **Grid overlay** for alignment

## Architecture

```
SimplePanel → CanvasPanel (main logic)
                ├── useGrafanaDataMap    — maps Grafana DataFrames → DeviceItem[]
                ├── useCanvasController  — all canvas state + persistence via onOptionsChange
                ├── CanvasStage          — SVG root, pan/zoom pointer events
                │     ├── GridLayer      — background grid
                │     ├── LinkLayer      — SVG lines between nodes
                │     └── NodeLayer → NodeShape  — individual draggable nodes
                ├── Toolbar              — add node, add from data, reset/fit view (edit mode only)
                ├── MiniHud              — viewport info overlay
                └── NodeInspector        — selected node details, delete, start/cancel link
```

## Data model (persisted in panel options)

```ts
SimpleOptions {
  editMode: boolean       // show toolbar & drag handles
  showGrid: boolean       // grid overlay
  canvas: {
    viewport: { x, y, scale }
    nodes: CanvasNode[]   // nodeId, kind, x/y/w/h, label?, dataId?
    links: CanvasLink[]   // linkId, fromNodeId, toNodeId, dataId?
  }
}
```

`NodeKind`: `'switch' | 'router' | 'generic'`

State is held locally in `useCanvasController` and committed to Grafana via `onOptionsChange` on pointer-up/commit. Live updates (dragging) stay local for performance.

## Data binding

`useGrafanaDataMap` turns Grafana DataFrames into a `DeviceMap` keyed by device ID.

DataFrames must expose these field names (case-insensitive):
- **id**: `id`, `device_id`, `deviceid`
- **name**: `name`, `device`, `hostname`, `label`
- **value**: `value`, `val`, `metric`, `state`, `status`

The bound value drives node fill color via Grafana thresholds/mappings (`fieldConfig.defaults`).
